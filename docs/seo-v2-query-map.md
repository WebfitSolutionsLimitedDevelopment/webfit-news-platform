## V2 rules

1. One primary query per page. Do not create another evergreen page targeting the same core query unless there is a clearly different intent.
2. Put the primary query naturally in the title, H1 and opening copy.
3. Put the answer/calculator near the top of the page. Do not make users scroll through generic SEO copy first.
4. Use secondary queries in descriptive H2/H3 headings and FAQs where they genuinely match the page content.
5. Keep one self-referencing canonical on `https://webfitnews.com`.
6. Use contextual internal anchors that describe the destination query.
7. Keep official NZ government sources visible and current.
8. Update titles/descriptions from Search Console data when impressions are high but CTR is weak; strengthen content when average position is roughly 5–20.
9. Do not keyword-stuff, create doorway pages or duplicate calculator content simply to chase variants.
